# Критичний аналіз контенту та боротьба з галюцинаціями ШІ

Інтерактивний урок для 10 класу курсу «ШІ та суспільство». П'ять модулів, максимум **100 балів**. Працює локально та на GitHub Pages, без сервера і зовнішніх бібліотек.

## Запуск

1. Розпакуйте архів і завантажте `index.html`, `style.css`, `app.js`, `README.md` у корінь репозиторію GitHub.
2. Відкрийте **Settings → Pages → Build and deployment → Deploy from a branch**, виберіть `main` та `/ (root)`, збережіть.
3. Дочекайтеся появи адреси сайту в налаштуваннях Pages.
4. Учні відкривають сайт, виконують завдання та натискають **«Завантажити результат .md»**.

Можна також відкрити `index.html` подвійним натисканням без інтернету.

## Модулі й бали

| Модуль | Балів |
|---|---:|
| Теорія, 4 розділи | 0 |
| Симулятор, 3 ситуації × 10 | 30 |
| Інтерактивна вправа, 5 завдань × 4 | 20 |
| Тест, 12 запитань × 2,5 | 30 |
| Аналітика, 2 відповіді × 10 | 20 |
| **Усього** | **100** |

Симулятор і тест перевіряються автоматично. В інтерактивній вправі та тесті бал за правильну відповідь нараховується після перевірки. Аналітичні відповіді оцінює учень за прозорою рубрикою (попередній бал), а вчитель підтверджує або коригує оцінку після прочитання експортованого файлу. Результат у браузері не передається на сервер і не зберігається в базі даних. Учень сам надсилає файл учителю.

**Важливо:** файл `.md` створюється у браузері на пристрої учня; він не потрапляє автоматично до GitHub. Учитель збирає файли через звичний канал (наприклад, Google Classroom). Підсумковий бал із самооцінюванням є попереднім.

## Освітня мета

Учні розрізняють факт, припущення та вигадану відповідь; застосовують перехресну перевірку, перевіряють джерела й цитати; обґрунтовують відповідальне використання генеративного ШІ.
